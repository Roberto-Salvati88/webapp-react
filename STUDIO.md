# webapp-react

1. Avvia prima il backend (cartella 37-webapp-express/soluzione-studio)
2. Copia `.env.example` in `.env`
3. `npm install`, poi `npm run dev`

Schema (milestone 0): DefaultLayout (navbar + Outlet) → HomePage (lista di MovieCard) e MoviePage (dettaglio + ReviewCard + ReviewForm).
Domande d'esame: perché serve CORS, perché la fetch sta in useEffect, cosa fa useParams, perché dopo il POST ricarico i dati.
